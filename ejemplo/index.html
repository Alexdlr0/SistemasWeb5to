Conceptos Clave

HTML Semántico

Uso estructurado de etiquetas como section, article, nav y header en lugar de usar puros divs.

Flexbox

Perfecto para alineación unidireccional, como la barra de navegación o centrar elementos.

CSS Grid

Ideal para maquetación bidimensional, como esta cuadrícula de tarjetas que se adapta a la pantalla.
